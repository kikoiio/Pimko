## 已有覆盖

| 层 | 可执行入口 | 能证明什么 | 不能证明什么 |
|---|---|---|---|
| 剪辑行为 | `npm run check:editing` | 字幕时间映射、非法计划、边界速度、模型 HTTP 错误、撤销历史、缓存与失败清理 | 真实 LLM 理解指令、可听切点与画面观感 |
| 原有素材回归 | `npm run check:fixtures` | 7 个合成素材的探测、静音、mock 建稿与实际导出 | 全静音真实转写不会幻听 |
| 实际渲染冒烟 | `npm run smoke` | 变速、配乐、叠化、预览与导出音画哈希一致、旧项目尺寸恢复 | 所有编码格式、长片和中断恢复 |
| 界面闭环 | `npm run test:ui`（云端 Xvfb） | 导入、画面比例、字幕外观修改、预览缓存/失效、连续修改/撤销、导出播放 | 人工视觉/听觉评价；真实模型连续修改 |
| 真实转写 | `npm run check:fixtures -- --transcribe` | 合成英文口播与公开中文演讲有词时间和最低词数 | 逐字准确、多人、方言、噪声/弱音、幻听 |
| 新边界语料 | `npm run fixtures:boundaries` + `npm run check:boundaries -- --render` | 见边界清单与 `check-results.json`；八个可渲染条目走实际渲染器 | 其余边界是人工探测，不等于产品支持 |
| MCP | `npm run smoke:mcp` | 外部客户端建稿→修订→导出 | 完整协议兼容、并发客户端和恶意输入鲁棒性 |

31 项离线测试 = 原有 27 项 + 新增 4 项顶层测试；参数化子输入不重复计数。执行记录以实际日志为准。

| HDR/HEVC/10-bit/多音轨/字幕轨 | 手工用例中记录为条件项 | 对应合法样片与环境兼容矩阵，当前没有生成 |

| 中断与并发 | 手工步骤定义预览/导出时操作、重启恢复 | 自动化进程终止/并发 IPC 验收；不应为了“过测”实现新功能 |

## 测试结果规则

- `未运行`：有明确操作与预期，但没有执行证据。
- `阻塞`：例如真实服务限流、缺少对应素材或环境，不算通过。
- `通过`：对应层的具体断言通过；不能推广成所有产品能力通过。
- `失败`：记录期望、实际、素材 ID、应用提交、provider/model（不记录密钥），保留可复现步骤。
- `超出当前范围`：例如多素材、B-roll、裁切，不纳入现有能力的通过率；依然记录边界提示是否清楚。

一轮体验结束后先汇总缺陷与复现，不自动扩大功能范围。最短体验路线与完整人工用例见 [当前能力验收](testing-acceptance.md)。
