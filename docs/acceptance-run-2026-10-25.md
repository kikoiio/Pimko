## 3. 真实缺陷清单（按影响排序）

### D1. 单个损坏修订 JSON 拖垮整个项目列表（FA-07a，I）
- **现象**：`projects/<id>/` 下任一修订文件非法 JSON 时，`FsProjectStore.list()` 抛错被吞 → 最近项目列表整体为空，**无关的正常项目也不可见、不可恢复**。
- **证据**：构造 2 项目（1 正常 + 1 含坏文件），卡片 0、API listProjects 0；record: `store/FA-07a-I`。
- **复现**：向任一项目目录写一个 `{invalid` 的 `.json`，重启应用。
- **影响**：一处磁盘小损伤放大为全部工作丢失的观感（数据仍在磁盘，仅不可见）。

### D2. 双击「发送」产生重复修订（CC-01，M）
- **现象**：快速双击发送（或连按 Enter）同一反馈，产生 **3 条修订/3 个气泡**（期望 1 条）；`speed=2` 被叠加两次进最终时间线之外的冗余链。
- **证据**：气泡 1→3、磁盘修订 1→3；截图 `media/CC-01-M/after-burst.png`。
- **根因**：`stage==='ready'` 守卫在 await 返回前不阻止第二次点击（无 in-flight 锁）。
- **影响**：撤销链被污染；文档 §13 预告的重点风险确认成立。

### D3. 快速连点撤销/音量档后 UI 与磁盘不一致（CC-02，M）
- **现象**：双击撤销 + 连点 轻/标准/响 后，UI 展示的修订 id ≠ 磁盘最新修订 id（`4ab13765` vs `4de04c47`）；最终 gainDb 取决于接受顺序而非最后点击。
- **证据**：修订链 10 条全记录在案；截图 `media/CC-02-M/cc02-final.png`。
- **影响**：并发操作下最终状态不确定，用户看到的可能不是磁盘真值。

### D4. 1fps 极稀疏帧率素材导出挂起（IM-13/low-fps，M）
- **现象**：`one-fps.mp4` 导出时「成片预览」300 秒不出现，无错误提示。
- **层定位**：用渲染器同款 ffmpeg 命令直裁同源 **0.2 秒成功** → 挂起在应用管线层（疑点：`-r 30` 重采样 1fps 源或 concat/校验环节）。
- **复现**：mock 导入 `sample-assets/boundaries/one-fps.mp4` → 生成成片。

### D5. 真实口癖删除会切掉邻词（ED-05，R）
- **现象**：F1（英文，含 um/uh）要求删口癖后，30 个有效词丢 2 个——「PIMCO.」与「words.」（句尾词被绕口癖区间连带切掉）。
- **证据**：词级对照 record `real/ED-05-R`；注意 whisper 把 "Pimko" 听成 "PIMCO."，词表以转写为准。
- **影响**：轻微可感知的内容损失；需逐剪口听感确认（样品未含此项，可补）。

### D6. 停顿压缩反馈保留率 8/9 词（ED-07，R）
- **现象**：F4「压缩长停顿，保留全部话语」后有效词保留 8/9（88.9%，低于 90% 断言线）；无整体加速、时长正确缩短。
- **证据**：record `real/ED-07-R`。属边界质量：接近但未达自定阈值，如实记失败待人工听感裁决。

### D7（观察项）. 长音频导入 33 分钟（IM-10，R）
- **现象**：5 分钟合成口播建稿耗时 1972s（目标 ≤120s），未限流、无假死，纯粹慢（逐段 ffmpeg+转写+LLM 决策链在长转写下多轮往返）。
- **证据**：record `real/IM-10-R`。按文档记性能失败；不宣称存在长片性能承诺。
